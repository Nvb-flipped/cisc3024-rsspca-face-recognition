# Report typefaces

The report and figure generator use these unmodified Latin Modern OpenType fonts. Latin Modern Roman is used for prose and labels, Latin Modern Mono for code and paths, and Latin Modern Math for equations.

- Roman and Mono files come from the `fonts/opentype/public/lm` directory in the [CTAN Latin Modern package](https://ctan.org/pkg/lm). See [the accompanying license](GUST-FONT-LICENSE-LM.txt).
- The Math file comes from the `opentype` directory in the [CTAN Latin Modern Math package](https://ctan.org/pkg/lm-math). See [the accompanying license](GUST-FONT-LICENSE-LM-MATH.txt).

The project loads these files directly, so generating figures and compiling the report require no system font installation.
